# 0.3.0 · 六项功能交付

当前为代码交付，默认仍是本机模式；没有替用户注册账号、创建付费云资源、真实发通知或向好友发送邀请。

| 功能 | 使用入口 | 已实现的行为 |
| --- | --- | --- |
| 合并提醒＋免打扰 | 设置 → 合并提醒与免打扰 | 同一时段合并，或每天一次汇总全部当日未确认任务；睡眠时段内跳过微信发送、不补发 |
| 自定义重复周期 | 新建／编辑任务 | 每天、周一至周五、自选星期；详情可暂停一周，7天后按原周期恢复 |
| 重要好友置顶 | 表单开关或任务详情 | 未确认优先，未确认中置顶优先，再按时间排序 |
| 快速复制任务 | 任务详情 → 复制为新任务 | 沿用周期、时间、备注和文案；名称留空，原任务不变，不复制临时暂停与置顶 |
| 离线查看与待同步 | 云模式；设置 → 离线与同步 | 身份验证后的缓存读写、持久队列、网络恢复同步、回执去重、冲突保留、明确放弃草稿 |
| 双方共同任务 | 今日／设置 → 共同任务 | 仅两人，24小时邀请，主动同意后共享当日确认，各自可撤销，支持退出与关闭 |

## 默认规则

使用北京时间。“周一至周五”指星期，不处理法定节假日调休。暂停一周包含今日起7天，恢复日再按原星期规则判断。

旧任务没有周期字段时按每天处理，旧设置按任务时间提醒且不开启免打扰，不擅自更改已有任务的行为。

统一汇总按你选择的时点列出当天尚未确认的全部任务，包括原提醒时点更晚的任务。免打扰时段的计划直接跳过，不补发；汇总时间不能设在免打扰内。真实微信通知仍需要合适的模板和主动订阅。

## 手机日历

日历独立于微信发送策略，不应用本程序的睡眠时段和汇总设置。每天任务创建每日日程，周一至周五／自选星期会为对应星期分别创建每周日程，添加前说明数量；中途取消保留已添加线索，下次可补齐未完成的星期。已有日历任务不会因为小程序改时、置顶、暂停或删除自动变化。

## 离线同步

本机模式一直使用本机存储；云模式第一次打开／每次冷启动需先联网核对身份，再允许使用当前用户的离线缓存。无法核对身份时不猜测上次账号。网络变差后，可查看已有缓存并把修改保存在持久队列；UI显示“待同步”，收到服务器回执才移出队列。

每个操作有唯一ID，回执丢失后重试不重复创建任务。云端数据有版本控制：其他设备先修改时，本机草稿保留，不静默覆盖；可保持草稿稍后处理，或明确放弃本机待同步修改并重新读取云端。放弃操作需要先成功取得云端快照，断网时不会丢草稿。

其他设备清空数据后，旧数据空间的离线队列不能重建已清空的数据。缓存与私人队列按服务器返回的用户数据空间隔离；不使用客户端提交的OPENID决定所有者。

当前离线缓存与云端快照为小规模完整快照设计。大量长期记录或大规模用户运营前，需要增加历史分页、缓存容量与日志保留策略。修改同步状态不等于已读，更不代表抖音操作完成。

## 共同任务

创建后主动生成邀请，再由你选择好友发送。邀请最多一位其他参与者，24小时过期，重新生成使旧邀请失效；接收者先看到名称、平台与共享说明，点击“同意加入”后才成为参与者。

仅双方可查看状态；确认只影响自己，按日重置显示。页面不返回对方OPENID，不共享私人任务、备注、快捷文案或聊天。发起人可关闭，参与者可退出。共同任务需联网，离线时不显示猜测的对方状态。共同任务的私人提醒需双方各自创建和授权，不会自动催促对方。

## 验证与待实测

见 `verification.md`。自动化使用内存数据库与模拟微信接口覆盖两位用户、断网、回执丢失、冲突和跨日；浏览器预览是页面流程模拟，不能替代微信开发者工具编译与真机测试。共同任务的微信分享、真实云事务、日历授权和通知仍须在自有账号环境验收。
