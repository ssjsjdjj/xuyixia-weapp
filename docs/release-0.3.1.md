# 0.3.1 · 今日清单体验优化

本版优化每天打开小程序、查找任务、手动确认和撤销的过程，不需要迁移已有任务或重新部署云函数。

- 默认显示待确认任务；切换“已确认”或“全部”即可找回完成任务。状态数量对应当前平台与关键词，首页总进度仍统计全部今日任务。
- 确认后任务移到已确认列表，保留“撤销刚才操作”；全部确认后的空列表可直接查看已确认任务。
- 清除搜索只清文字，保留平台与状态；重置筛选才恢复默认的全部平台、待确认。
- 根据北京时间显示“尚未到处理时间”“还有N分钟”或“已到你设置的处理时间”；完成任务不再显示待处理时间提示。提示不代表系统通知已经送达，也不推断平台火花或打卡状态。
- 同一天刷新时保留原清单；刷新失败明确标注旧数据并暂时关闭确认，重试成功后恢复。首次读取失败仍显示错误页；跨日清空旧日显示，避免混用昨日任务。
- 前台每30秒更新时间提示、同步提示和日期；离开页面即停止。它不在后台运行，不发送微信消息。
- 修复离线撤销未显示待同步、确认保存期间跨零点后撤销日期可能错位的问题；原有置顶和时间排序保持不变。

已通过73项自动化测试与静态检查，浏览器预览用于375px／320px流程走查。微信原生编译、真机通知与真实云环境仍需按 `verification.md` 验收。
