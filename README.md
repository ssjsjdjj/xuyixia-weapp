# 续一下 · 微信小程序

原生微信小程序源码，包含抖音续火花任务、微博打卡任务、今日清单、手动完成与撤销、历史记录、提醒设置及可选云后端。

当前版本 **0.3.0**：新增合并汇总／睡眠免打扰、重复周期／暂停一周、重要对象置顶、快速复制任务、云模式离线队列与双方共同任务。入口和边界见 [本版功能说明](docs/release-0.3.0.md)。0.2.0 的体验走查仍保留在 [体验优化记录](docs/ux-walkthrough.md)。

可直接在浏览器打开 [交互演练页](docs/interaction-preview.html)，其中执行相同页面逻辑，日历、消息与剪贴板为模拟接口，不需要登录。预览示例任务保存在独立的浏览器数据空间，不会进入微信小程序。修改页面后运行 `node scripts/build-preview.js` 更新预览。

默认是**本地保存模式**，没有演示任务，不需要购买服务器或填入密钥即可查看界面、创建任务。此模式关闭小程序后不运行后台计时，也不会发送微信通知。手机日历入口需要支持该能力的微信真机、相应授权和可用的小程序账号；游客模拟器不能替代真机验证。

## 现在如何运行

1. 安装微信官方开发者工具，选择「导入项目」。
2. 项目目录选择本 README 所在的 `xuyixia-weapp` 文件夹，根目录已有 `project.config.json`。
3. 目前没有 AppID，可选择工具提供的「测试号／游客模式」（以当前工具入口为准）；如果工具要求真实 AppID，先注册小程序后填入。不要把 AppSecret 写进源码。
4. 保持 `miniprogram/config.js` 的 `storageMode: 'local'`，编译入口为 `pages/today/index`。无需 npm 构建前端。
5. 点「新建提醒」，添加好友或微博打卡对象，设置时间。验证完成、撤销、编辑、暂停、删除和记录。

本次未使用微信开发者工具进行实际编译，也没有真机验证结果。已验证的自动化检查和未验证项目见 `docs/verification.md`。

## 已实现的行为

- 今日：按北京时间生成每日待办；搜索对象、按平台筛选；未确认优先；逐项确认完成。
- 新建与编辑：任务类型、对象昵称、提醒时间、备注、自备招呼文案；表单校验和提交保护。
- 详情：复制自备文案、确认完成、撤销、启用／暂停、编辑、删除、添加重复日历。
- 记录：按日期查看用户确认记录，可撤销历史误点；删除任务仍保留记录快照。
- 设置：新建任务的默认时间、订阅入口、数据存储说明、隐私说明、清除数据。
- 本地持久化：重启后保留；损坏数据不静默覆盖。清除或卸载微信可能删除本机数据，本地模式不跨手机同步。
- 云端：按微信 OPENID 隔离的任务 API、定时扫描、消息模板映射、发送去重和失败账本，待配置部署。
- 周期：每天、周一至周五、自选星期；暂停7天后按原周期恢复；置顶在未确认任务中优先。
- 复制：沿用时间、周期、备注和文案，新对象名称留空；原任务不变，置顶与临时暂停不复制。
- 汇总：设置中可选择统一汇总时间；免打扰内的微信计划跳过、不补发，不影响独立的系统日历。
- 离线：云模式在本次打开在线验证身份后可缓存查看和编辑；待同步状态、冲突和丢弃草稿入口可见。冷启动完全离线不展示上一账号缓存。
- 共同任务：发起、生成24小时邀请、主动加入、各自当日确认、退出或关闭；需要部署云端并联网。各自的私人提醒与授权独立。

“快捷续火花”是辅助处理入口。应用不获取抖音/微博密码，不替个人账号自动发私信，不读取火花状态，不自动完成微博签到。确认状态表示用户在本工具里做了确认。

## 以后启用真实提醒

有小程序账号、可用服务类目及获准订阅模板后，按 [云部署说明](docs/cloud-setup.md) 部署函数和数据库，然后修改 `miniprogram/config.js`：

```js
module.exports = {
  storageMode: 'cloud',
  cloudEnvId: '你的云环境ID',
  apiFunctionName: 'xuyixia-api',
  subscriptionTemplateId: '你获准的模板ID'
};
```

本地和云端是独立数据空间，切换模式不会自动上传或迁移原有任务。云模式在本次打开验证身份后，断网修改会保存在本机并显示待同步；同步成功前，云端仍按原计划提醒。冷启动时无法联网验证身份则不展示旧缓存。

微信一次性订阅需用户主动选择；每次授权不代表永久每天推送。客户端显示接受授权，也不等于后续已发送或已读，最终以微信发送接口结果为准。[腾讯云文档](https://cloud.tencent.com/document/product/1301/103770)

日历是用户自选的固定重复提醒。完成、暂停、删除或改时不会自动更新手机日历，用户须在日历中独立维护；系统通知设置也可能影响提示。[微信官方接口定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)

## 检查源码

需要 Node.js 20 或以上；根项目没有运行时 npm 依赖。

```powershell
npm test
npm run check
```

仅在部署云函数时需要为各函数安装其 `package.json` 的依赖，推荐使用微信开发者工具「上传并部署：云端安装依赖」。

## 源码结构

```text
miniprogram/
  app.js / app.json / app.wxss
  config.js              本地／云模式配置
  pages/                 八个原生页面
  services/store.js      本地持久化与云端代理
  services/reminders.js  订阅授权与系统日历
  utils/domain.js        日期、验证、今日状态
cloudfunctions/          API 与定时提醒函数
tests/                   本地逻辑与页面流程测试
docs/                    部署、验收说明
```

正式提审前需把平台隐私声明、服务类目、消息模板和运营方信息填写为实际内容，并完成 iOS／Android 真机验证。当前代码未上传至任何微信账号或云环境。
